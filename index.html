From a technical perspective, xu60 is not a new contribution. it 1) indexes a content addressable archive (git for now) and 2) provides a few endpoints for querying and slicing objects in the archive. It is as much a spec as it is an implementation. but an implementation is necessary in order to understand xu60. May the Curse of Xandadu be lifted. The whole of the project is as a series of "what if?" questions: "what if we treat referentiality as a first class citizen?" "what if we could see aboutness instead of looking through it?" "what if we picked up a different fork from the hypertext road, dusted it off, and made soup?"
